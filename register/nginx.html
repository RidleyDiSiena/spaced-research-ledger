Where the Cryptography Comes From

This component does not implement everything it is asked about. What it inherits, from what, and at which version:

  • OpenSSL – linked. Inherits: TLS 1.3. nginx implements no cryptography: it links a TLS library, and on the overwhelming majority of deployments that is OpenSSL. The project’s own post-quantum article is written entirely in terms of which OpenSSL the binary has, down to warning which base image lacks it. No pin, because the linked version is chosen by whoever built the package rather than by nginx – which is exactly why the cell above cannot carry an nginx version either. capabilities says tls alone: the edge was written as [tls, x509] and the validator refused it, because x509 does not apply to a tls-terminator. That refusal is right. What a terminator does with a certificate – present it, prove possession of its key – happens inside the handshake and is the tls column’s authentication half; the x509 column is about generating, parsing and chain-building, which is the library’s job underneath. Widening the vocabulary to make the edge fit would have been the wrong direction. [2]

Notes

  • X25519MLKEM768, TLS 1.3: THE since IS NOT AN NGINX VERSION AND THAT IS THE HONEST ANSWER: no release of nginx added this. A binary linked against OpenSSL 3.5 or newer can negotiate the group; the same nginx on a distribution shipping OpenSSL 3.0 cannot, whatever its version number. The project’s own article makes the point by warning that its default container image is Debian 12, “which does not have PQC available”. available rather than default because the article configures ssl_ecdh_curve explicitly – nginx’s default for that directive passes OpenSSL’s own list through, so an untouched nginx on OpenSSL 3.5 probably does offer the group, and probably is not a citation.

Known Unknowns

Cells an engineer would ask about that no cited source has settled yet. not checked means nobody has searched. searching means fewer than 2 passes are done. none found means the search was completed and came back empty, and the artifacts examined are named; a result older than 90 days is marked for recheck.

  • ml-dsa / tls – searching, 1 of 2 passes: Whether nginx can serve an ML-DSA certificate is a different question from which group it negotiates, and the article does not touch it. It is largely OpenSSL’s answer again, but nginx has its own certificate loading and OCSP paths. Second pass: the nginx ssl module documentation, or an ML-DSA certificate actually loaded. Examined: NGINX community blog, PQC support in NGINX.
