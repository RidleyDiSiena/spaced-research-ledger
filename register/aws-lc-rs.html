Notes

  • ML-KEM, Primitive: The kem module documents ML_KEM_512, ML_KEM_768 and ML_KEM_1024 as a stable public API, not behind the unstable feature flag that gated ML-DSA until 1.18.1. The docs name no introducing version.
  • ML-DSA, Primitive: Stable API without the unstable feature flag from 1.18.1; described as not fully stabilised in February 2026.
  • ML-DSA, FIPS 140-3: ML-DSA APIs available under the crate’s FIPS build.
