Where the Cryptography Comes From

This component does not implement everything it is asked about. What it inherits, from what, and at which version:

  • AWS-LC – linked. Inherits: TLS 1.3. The vendor’s builds ship AWS-LC as the cryptographic library, which is where the post-quantum curves come from – the article says so directly: “This works because both versions ship with AWS-LC as their cryptographic library, which includes support for post-quantum curves.” A distribution-built HAProxy links something else and inherits that library’s answer instead, which is why this edge describes the vendor build specifically. [3]

Notes

  • X25519MLKEM768, TLS 1.3: A BUILD-PROVENANCE ANSWER, not a version answer. The same HAProxy version compiled by a distribution against OpenSSL does not have these curves; the vendor’s builds ship AWS-LC and do. available rather than experimental because those packages are ordinary general releases rather than a preview or a flag – but anyone reading the version number alone will get this wrong, which is why the caveat is in the cell rather than only in the release notes. Automatic fallback to classical curves means enabling it does not break old clients.
  • SecP256r1MLKEM768, TLS 1.3: The NIST-curve hybrid matters for anyone whose policy prefers a P-256 half, which in practice means CNSA-aligned and federal deployments.
