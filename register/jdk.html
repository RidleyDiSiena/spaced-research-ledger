Notes

  • ML-KEM, Primitive: JEP 496: native JCA engine classes, ML-KEM-512/768/1024.
  • ML-KEM, X.509: keytool generates ML-KEM key pairs and certificates; the certificate must be signed with a signature algorithm.
  • X25519MLKEM768, TLS 1.3: JEP 527 delivers hybrid TLS 1.3 key exchange in JDK 27, and the Curve25519 optimisation claim names X25519MLKEM768 as a group whose key generation it speeds up. Neither claim states the default group list, so ‘available’, not ‘default’.
  • ML-DSA, Primitive: JEP 497; JAR signing with ML-DSA from JDK 26.
