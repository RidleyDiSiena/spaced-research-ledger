Notes

  • ML-KEM, Primitive: Two parameter sets only – ML-KEM-768 and ML-KEM-1024. ML-KEM-512 is not named, which for a platform that ships one curated API surface is worth reading as a deliberate omission rather than an oversight, though the page does not say so.
  • ML-DSA, Primitive: ML-DSA-65 and ML-DSA-87 only; ML-DSA-44 is not named. The same curation as the KEM parameter sets.

Known Unknowns

Cells an engineer would ask about that no cited source has settled yet. not checked means nobody has searched. searching means fewer than 2 passes are done. none found means the search was completed and came back empty, and the artifacts examined are named; a result older than 90 days is marked for recheck.

  • ml-kem / fips – searching, 1 of 2 passes: The same shape as Windows, from the same scan. Apple holds 32 corecrypto certificates and the one read in detail (5387, Apple corecrypto Module 18.3 [Apple silicon, Kernel, Software, SL1]) lists 52 approved algorithms, none post-quantum. Two Apple corecrypto Module OS 26 submissions have been in Review since 30 and 31 July 2026, and OS 26 is exactly the release that shipped ML-KEM to CryptoKit – so the pending modules are the ones that would carry it, and calling this absent would be wrong. Second pass: those certificates when they issue. Examined: CMVP validated module search, vendor Apple (32 corecrypto modules), certificate page 5387 (approved-algorithm list), CMVP Modules In Process list.
  • ml-dsa / fips – searching, 1 of 2 passes: As ML-KEM, and for the same reason: shipped in CryptoKit with the 26 releases, absent from every issued corecrypto certificate, and blocked from absence by the OS 26 modules still in Review. Examined: certificate page 5387 (approved-algorithm list), CMVP Modules In Process list.
  • slh-dsa / primitive – searching, 1 of 2 passes: The Apple Platform Security page names ML-KEM and ML-DSA and no other post-quantum family. It is an overview rather than an API enumeration, so this is unknown, NOT a cited absence – the distinction the register exists to keep. Second pass: the CryptoKit framework reference on developer.apple.com, which does enumerate types. Examined: Apple Platform Security, Quantum-secure cryptography in Apple operating systems.
  • lms-hss / primitive – searching, 1 of 2 passes: As SLH-DSA: not named on the page read, and the page does not enumerate. Apple signs firmware, so stateful hash-based signatures are a question worth asking of corecrypto specifically. Examined: Apple Platform Security, Quantum-secure cryptography in Apple operating systems.
