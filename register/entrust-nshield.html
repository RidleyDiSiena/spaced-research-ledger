Notes

  • ML-KEM, PKCS#11: A CITED none, and the sharpest justification for this column in the register. The device implements ML-KEM – the primitive cell above says so on the same vendor’s word – and an application cannot reach it through PKCS#11 at all, only through Entrust’s proprietary nCore API. A register with only a primitive column would show this device as ML-KEM-capable and leave the reader to discover the interface gap after buying it. “Currently” is the vendor’s word and this cell should be rechecked when Security World moves.
  • ML-DSA, Primitive: Natively in firmware, which Entrust distinguishes from its earlier Post-Quantum Option Pack – that pack made the pre-standard candidates (Dilithium, Kyber, SPHINCS+, Falcon) available inside the CodeSafe execution environment from 2022, which is a different and weaker claim than firmware support for the ratified standards.
  • ML-DSA, PKCS#11: All three parameter sets, through the standard interface.

Known Unknowns

Cells an engineer would ask about that no cited source has settled yet. not checked means nobody has searched. searching means fewer than 2 passes are done. none found means the search was completed and came back empty, and the artifacts examined are named; a result older than 90 days is marked for recheck.

  • lms-hss / primitive – searching, 1 of 2 passes: The Post-Quantum Option Pack is described as enabling “NIST approved code-signing with the Leighton-Micali Signature (LMS)”, which is LMS reachable through a product rather than a statement about firmware support in the 13.8 line. The two are different claims and the sources read do not settle which applies now. Second pass: the Security World 13.9 release notes’ algorithm list, or the option pack integration guide’s current edition. Examined: Entrust nShield 5 CAVP announcement (2025-09), nShield Security World v13.9.0 release notes, nShield Post-Quantum Cryptography Option Pack integration guide.
  • ml-dsa / firmware – searching, 1 of 2 passes: Whether the nShield firmware image is itself signed post-quantum is unstated in the material read. Second pass: the nShield 5s security policy for certificate 5329, which describes the firmware load test. Examined: Entrust nShield 5 CAVP announcement (2025-09).
