Notes

  • ML-KEM, SSH: HYBRID ONLY, BY POLICY, and the project says why in the same breath: the classical half runs in parallel and both outputs are hashed, so a break in the lattice half is not fatal. available rather than default because the page read does not state where the ML-KEM hybrids sit in PuTTY’s key exchange preference order, and this register does not infer a default from the presence of a feature – see the gap below. PuTTY shipped an NTRU Prime hybrid in 0.78, which predates most of the libraries in this register; that algorithm has no row here. WHAT WOULD SHARPEN THIS CELL: whether the ML-KEM hybrids sit at the top of PuTTY’s key exchange preference order, which is the difference between available and default and so between a feature and a deployment. That belongs here rather than in the gap list – a gap is a pair nobody has answered, not an answer somebody wants to be more precise about, and the validator enforces the distinction.

Known Unknowns

Cells an engineer would ask about that no cited source has settled yet. not checked means nobody has searched. searching means fewer than 2 passes are done. none found means the search was completed and came back empty, and the artifacts examined are named; a result older than 90 days is marked for recheck.

  • ml-dsa / ssh – none found 2026-09-13: Searched twice and found no implementation, and the second pass found the reason: THERE IS NO SETTLED STANDARD TO IMPLEMENT. ML-DSA for SSH sits in competing INDIVIDUAL drafts – draft-rpe-ssh-mldsa-03 (16 April 2026, standards track, names mldsa-44/65/87 and says implementations SHOULD do mldsa-65) and draft-sfluhrer-ssh-mldsa-06 – with neither adopted by the sshm working group, while the hybrid KEY EXCHANGE half went the other way and is an adopted working-group document (draft-ietf-sshm-mlkem-hybrid-kex-10). That asymmetry is the finding: SSH’s post-quantum key agreement is standardised and shipping by default, and its post-quantum AUTHENTICATION has not converged on a name yet. Recheck when a draft is adopted, not before – the implementations are waiting on the same thing. Examined: IETF datatracker: draft-rpe-ssh-mldsa-03 (individual, standards track), IETF datatracker: draft-sfluhrer-ssh-mldsa-06 (competing individual draft), IETF datatracker: draft-ietf-sshm-mlkem-hybrid-kex-10 (adopted, for contrast), OpenSSH release notes 10.1, 10.0, 9.9, libssh 0.12.0 release announcement, PuTTY change log and wishlist.
