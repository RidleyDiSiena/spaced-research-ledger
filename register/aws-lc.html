Notes

  • ML-KEM, Primitive: ML-KEM-512/768/1024; implementation imported from mlkem-native v1.1.0 into the FIPS module.
  • ML-KEM, TLS 1.3: Pure ML-KEM groups are listed beside the hybrids.
  • ML-KEM, FIPS 140-3: ML-KEM is inside the AWS-LC 3 modules: certificates 5314 (static) and 5298 (dynamic), both issued June 2026. The 2026-09-12 CMVP scan read the approved-algorithm list of every AWS-LC certificate, and certificate 4631 – which the ledger claim cites and an earlier version of this note listed – does NOT name ML-KEM; it is the 2023 module covering AWS-LC FIPS 1.0.2 and 1.1.0. Whether ML-KEM is on in approved mode by default is not stated anywhere, so ‘available’ not ‘default’.
  • X25519MLKEM768, TLS 1.3: The project’s post-quantum README lists X25519MLKEM768, SecP256r1MLKEM768 and SecP384r1MLKEM1024 among its supported TLS groups, alongside pure ML-KEM variants. Whether any is offered by default is not stated there.
  • SecP256r1MLKEM768, TLS 1.3: Listed in the same set.
  • SecP384r1MLKEM1024, TLS 1.3: Listed in the same set.
  • ML-DSA, Primitive: ML-DSA-44/65/87.
  • ML-DSA, TLS 1.3: TLS 1.3 signature scheme, per the project’s release history.

Known Unknowns

Cells an engineer would ask about that no cited source has settled yet. not checked means nobody has searched. searching means fewer than 2 passes are done. none found means the search was completed and came back empty, and the artifacts examined are named; a result older than 90 days is marked for recheck.

  • ml-dsa / fips – none found 2026-09-12: Settled as far as the lists can settle it, by the CMVP reverse scan the previous pass asked for: no AWS-LC module with an issued certificate names ML-DSA in its approved-algorithm list, and the two AWS-LC 4 modules in the queue since 2026-08-14 have no published algorithm list at all. So ML-DSA is not inside a validated boundary today, and whether it is inside the pending submission is unpublished – which is why this stays a gap rather than becoming a none cell. Examined: CMVP validated module search, vendor Amazon Web Services (6 AWS-LC modules), certificate pages 5429, 5314, 5298, 5146, 4816, 4631 (approved-algorithm lists), CMVP Modules In Process list (AWS-LC 4, dynamic and static).
