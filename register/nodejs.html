Where the Cryptography Comes From

This component does not implement everything it is asked about. What it inherits, from what, and at which version:

  • OpenSSL – linked, pinned at OpenSSL 3.5 (24.x line). Inherits: Primitive, TLS 1.3, X.509, FIPS 140-3. Node.js statically links OpenSSL and exposes it through node:crypto. The project’s own 24.7.0 release post attributes the post-quantum algorithms to OpenSSL 3.5 on the 24.x line, so what Node offers advances only when Node rebuilds against a newer OpenSSL. [3]

FIPS 140-3

Node.js holds no FIPS 140-3 certificate of its own. It takes its cryptography from OpenSSL (linked, at OpenSSL 3.5 (24.x line)), and OpenSSL holds FIPS 140-3 certificates 4985, 4811, 4282, and has a module in the CMVP queue. Whether a given algorithm is inside that validated boundary is OpenSSL’s answer, not this component’s: see the OpenSSL page. Running in an approved mode also needs the validated version on a tested operating environment, which no register can tell you.
