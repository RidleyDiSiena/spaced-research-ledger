Notes

  • ML-KEM, Primitive: ML-KEM-768 in softoken/FreeBL from 3.105 (vendored Libcrux); ML-KEM-1024 from 3.118.
  • ML-KEM, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • X25519MLKEM768, TLS 1.3: Group mlkem768x25519 available from 3.105, default from 3.118.
  • SecP256r1MLKEM768, TLS 1.3: Release notes bug 1983313 adds secp256r1mlkem768 alongside secp384r1mlkem1024; the same bug made mlkem768x25519 the default, so this one is offered but not preferred.
  • ML-DSA, Primitive: Sign/verify interfaces.
  • ML-DSA, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • SLH-DSA, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • LMS / HSS, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • XMSS / XMSS^MT, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.

Known Unknowns

Cells an engineer would ask about that no cited source has settled yet. not checked means nobody has searched. searching means fewer than 2 passes are done. none found means the search was completed and came back empty, and the artifacts examined are named; a result older than 90 days is marked for recheck.

  • ml-dsa / tls – none found 2026-09-12: Searched twice on 2026-09-12 and found nothing: 3.118 adds ML-DSA only as SGN and VFY interfaces, the low-level sign and verify operations, and 3.124 mentions no post-quantum work at all. The ML-KEM groups are named release by release in the same notes, so their silence on ML-DSA in tls is meaningful rather than incidental. Examined: NSS 3.118 release notes, NSS 3.124 release notes.
