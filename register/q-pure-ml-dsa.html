ML-DSA (FIPS 204) through the component’s own API, in a general release, without a build flag or preview channel. Pure rather than composite: this asks about ML-DSA on its own, not paired with a classical algorithm in one signature. The bar is available, so a component that ships it but does not select it by default still counts – the question is whether you can use it, not whether you get it without asking.
