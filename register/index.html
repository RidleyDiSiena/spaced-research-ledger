Libraries and Language Stacks

The code almost everything else inherits its cryptography from: the general-purpose libraries, the language standard libraries and runtimes, and the protocol implementations that sit directly on them. This is where a migration usually starts, because a component here decides what thousands of applications can negotiate.

Reading the Table

Each family column shows the highest standing any member algorithm reaches in the family’s headline capability. Open a component for every row and its evidence. The scale, lowest first:

  • none A source states the component does not support it, or has decided not to. Not the same as unknown: this needs a citation too.
  • planned Announced, roadmapped, or in an open pull request or draft release note. Nothing a user can run yet.
  • experimental Runnable but gated: a build flag, an unstable feature, a preview or beta channel, a separate provider or plugin that the project itself ships or endorses.
  • available Shipped in a general release, usable through the normal API or configuration, but not selected unless the user asks for it.
  • default On without configuration in the capability’s own context (see capabilities.yaml). For a TLS key exchange this means offered in the default group list; for a signature it means accepted by default in verification paths; for a FIPS module it means inside the validated boundary.
  • unknown No cited cell and no gap recorded – the question has not been asked.

Answers counts what the register knows about a component: cells backed by a cited source, plus absences somebody searched for and confirmed. Open counts the questions still to be worked. There is no percentage, because there is no honest denominator: most algorithm and capability pairs are combinations nobody would implement, and counting them would understate the work done.

An empty cell says what was done about it: not checked nobody has looked; searching, 1 of 2 passes a pass is done, not yet the second; none found 2026-01-01 searched to completion and came back empty, with the artifacts named on the component page. A completed search older than 90 days is marked for recheck.

Every chip states its own meaning in words, so the colour is a shortcut rather than the message: the table reads the same in greyscale, in print, and to a reader who does not separate the hues.
