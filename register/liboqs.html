Notes

  • ML-KEM, Primitive: Final FIPS 203 ML-KEM since 0.11.0. mlkem-native became the default implementation in 0.14.0 (the date this cell carried until patrol 2026-09-26 corrected it) and was updated to v1.2.0 in 0.16.0.
  • ML-KEM, TLS 1.3: Not liboqs’s job: the Open Quantum Safe project states that oqs-provider is the standalone OpenSSL 3 provider that brings liboqs-based key exchange and authentication into TLS 1.3, X.509 and CMS. liboqs is the algorithm library underneath. oqs-provider would be its own component, of a kind the phase 3 scope defers.
  • ML-KEM, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • ML-DSA, Primitive: Final FIPS 204 ML-DSA since 0.12.0. mldsa-native became the default implementation in 0.16.0, the date this cell carried until patrol 2026-09-26 corrected it.
  • ML-DSA, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • SLH-DSA, Primitive: 0.15.0 was the last release with pre-standard SPHINCS+; SLH-DSA supersedes it and SPHINCS+ was removed in 0.16.0.
  • SLH-DSA, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • LMS / HSS, Primitive: Same terms as the XMSS cell: default-off build flag, signing behind a HAZARDOUS_EXPERIMENTAL flag.
  • LMS / HSS, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • XMSS / XMSS^MT, Primitive: Was ‘available’, since not recorded, until patrol 2026-09-26: the project ships XMSS behind a default-off build flag and gates key and signature generation behind a second flag named HAZARDOUS_EXPERIMENTAL, which is what ‘experimental’ means on this scale. 0.16.0 fixed an out-of-bounds read in XMSS/XMSS^MT verification.
  • XMSS / XMSS^MT, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
