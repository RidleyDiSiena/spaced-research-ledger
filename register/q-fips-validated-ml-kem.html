ML-KEM named in the approved-algorithm list of a module with an ISSUED CMVP certificate – not a FIPS build, not a submission in the queue, not a vendor’s announcement. The bar is available, which on the FIPS scale means inside the validated boundary. Running in an approved mode additionally needs the validated version on a tested operating environment, which no register can tell you; this question answers only whether the algorithm is inside the boundary at all.
