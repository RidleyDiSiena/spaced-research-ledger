Notes

  • ML-KEM, IPsec / IKEv2: available rather than default: you write it into a proposal. WHY IPSEC IS THE EASY CASE, and worth understanding because it is the opposite of TLS: RFC 9370 lets up to seven ADDITIONAL key exchanges be layered on after the first, so ML-KEM is appended to a classical exchange rather than replacing it, and a deployment keeps its existing security properties while adding the new one. The hybrid is built by configuration rather than baked into a named group, which is why this register records it on the ML-KEM row and has no hybrid-group rows for IPsec at all. Four different implementations can supply the mathematics – Botan, wolfSSL, AWS-LC or strongSwan’s own ml plugin – so the answer travels with the build; that is prose here rather than a derives_from edge because strongSwan ships an implementation of its own.

Known Unknowns

Cells an engineer would ask about that no cited source has settled yet. not checked means nobody has searched. searching means fewer than 2 passes are done. none found means the search was completed and came back empty, and the artifacts examined are named; a result older than 90 days is marked for recheck.

  • ml-dsa / ipsec – none found 2026-09-13: Searched twice, no implementation found, and the shape of the gap is the same as SSH’s: the KEY EXCHANGE half is standardised and shipping (RFC 9370 additional key exchanges, which both components implement) while post-quantum AUTHENTICATION is not. RFC 7427 signature authentication carries an ASN.1 AlgorithmIdentifier, so ML-DSA is expressible in IKEv2 in principle – which makes the absence a choice about deployment rather than a protocol limitation. Neither project’s release notes mention it. Recheck alongside the SSH signature question; they are likely to move together, because both are waiting on certificate ecosystems rather than on code. Examined: strongSwan 6.0.0 release announcement and IKEv2 cipher suite documentation, Libreswan CHANGES through v5.5 (unreleased), RFC 7427 signature authentication (the mechanism that would carry it).
