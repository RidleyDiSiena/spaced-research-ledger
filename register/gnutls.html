Notes

  • ML-KEM, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • X25519MLKEM768, TLS 1.3: Experimental in 3.8.8; minimum liboqs 0.11.0.
  • ML-DSA, Primitive: Experimental ML-DSA from 3.8.9 via the leancrypto backend; 3.8.13 derives the public key from an expanded private key per RFC 9881.
  • ML-DSA, TLS 1.3: NEWS for 3.8.11: ML-DSA-44, ML-DSA-65 and ML-DSA-87 can be used to sign TLS handshake messages. The same release moved the implementation from draft-ietf-lamps-dilithium-certificates-04 to -12 with all three variants.
  • ML-DSA, X.509: NEWS for 3.8.10: the library and certtool support ML-DSA as defined in FIPS 204, based on the LAMPS certificates draft. 3.8.13 added deriving the public key from an expanded private key per RFC 9881.
  • ML-DSA, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • SLH-DSA, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • LMS / HSS, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • XMSS / XMSS^MT, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
