Notes

  • ML-KEM, Primitive: ML-KEM768 plus X-Wing (ML-KEM768 with X25519); the library’s first post-quantum primitive.
  • ML-KEM, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • X-Wing, Primitive: X-Wing, the hybrid of ML-KEM-768 with X25519, is marked DONE on the roadmap and shipped in 1.0.22. Recorded against the primitive column, not TLS: libsodium is not a TLS stack, and X-Wing is a KEM construction rather than the TLS group of the same shape. MOVED 2026-09-13 from the x25519mlkem768 row to the new x-wing row. The old note said in its own words that this was not the TLS group – the register simply had no row for the thing it actually was, and the rule is that a second component carrying something is the bar for adding one. Apple’s CryptoKit was that second component.
  • ML-DSA, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • SLH-DSA, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • LMS / HSS, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.
  • XMSS / XMSS^MT, FIPS 140-3: Not in any module of this project: the CMVP validated list and the Modules In Process list were scanned on 2026-09-12 and name none carrying it.

Known Unknowns

Cells an engineer would ask about that no cited source has settled yet. not checked means nobody has searched. searching means fewer than 2 passes are done. none found means the search was completed and came back empty, and the artifacts examined are named; a result older than 90 days is marked for recheck.

  • ml-dsa / primitive – none found 2026-09-12: Searched twice on 2026-09-12 and found nothing: the project’s own roadmap lists ML-KEM and X-Wing as DONE and carries no post-quantum SIGNATURE scheme at all, at any status. The two signature items it does list, batch signatures and a BLS consideration, are classical. This is the clearest ‘not on the path’ in the register: libsodium has chosen a post-quantum KEM and not a post-quantum signature. Examined: libsodium roadmap (doc.libsodium.org/roadmap), libsodium 1.0.22 release notes.
